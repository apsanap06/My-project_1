## House Price Prediction Model

This project uses **Linear Regression** to predict house prices based on a dataset of 7,120 records.

### Key Details

* **Features**: Includes 107 input variables such as `bath`, `balcony`, `total_sqft_int`, `bhk`, and one-hot encoded locations.
* **Preprocessing**: Data was checked for null values and duplicates before applying `StandardScaler` for feature scaling.
* **Model**: Built using `scikit-learn` with an 80/20 train-test split.
* **Performance**:
* **R² Score**: 0.8287
* **MAE**: 18.29
* **RMSE**: 58.54



### Stack

**Python** (Pandas, NumPy, Scikit-Learn).
